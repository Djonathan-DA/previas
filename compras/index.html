    Sincronização

    A lista fica guardada no seu repositório do GitHub. Os dois celulares que apontarem para o mesmo repositório enxergam a mesma lista. Sem internet o app funciona igual e sincroniza depois.

    🔒 O token fica só neste aparelho. Ele nunca é gravado no repositório nem enviado para outro lugar. Cada celular coloca o seu.

    Como criar o token (1 minuto)
    1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
    2. Generate new token.
    3. Em Repository access, escolha Only select repositories e marque só o compras-familia-dados.
    4. Em Repository permissions, ponha Contents em Read and write.
    5. Gere, copie e cole aqui. Guarde uma cópia: o GitHub só mostra uma vez.

    Dando acesso só a esse repositório, o token não serve para mais nada na sua conta.
